# Web and Email Experience Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn the 16 supplied designs and supplemental page specifications into a high-fidelity, responsive, accessible Chinese web application and a complete, privacy-safe email template set backed by real APIs and browser cryptography.

**Architecture:** Next.js App Router uses server-side session/state guards before rendering private shells and client islands only for forms, countdowns, uploads, and browser crypto. A restrained token system maps the supplied Inter/JetBrains Mono/material-symbol design language into build-time Tailwind CSS. API state—not demo state—drives every status and action. Email templates share a separate table-based 600px renderer with inlined CSS and plain-text equivalents.

**Tech Stack:** Next.js 16.3.0, React/DOM 19.2.8, Tailwind CSS/PostCSS 4.3.3, generated OpenAPI client, Web Workers, Playwright 1.62.1, axe Playwright 4.12.1, Handlebars 4.7.9, Juice 12.1.2.

## Global Constraints

- Normative inputs are `前端设计/DESIGN.md`, the 16 `screen.png`/`code.html` pairs, and `docs/06-page-specifications.md`. Real security/business behavior wins where a mock design conflicts.
- Visual thesis: “克制、可信、略带纪念性的数字档案工作台——暖灰纸面、石墨文字、单一黑色操作强调，状态色只承担风险语义。”
- Content plan: product surfaces start directly with orientation/status/action; the public legacy surface prioritizes owner identity, will content, verification digests/timeline, and one download action; no marketing hero or filler metrics.
- Interaction thesis: route/nav selection moves with a short shared transition; workflow states/countdowns reveal through restrained opacity/translate; upload/crypto operations expose honest progressive state. All motion is disabled/reduced under `prefers-reduced-motion`.
- Use cards only where the supplied design makes a region an interaction/status object. Prefer plain sections, dividers, tables, and whitespace elsewhere; do not convert the app into a generic dashboard-card mosaic.
- Use only Chinese UI copy and `YYYY-MM-DD HH:mm:ss（北京时间）`. Technical digests/IDs use JetBrains Mono.
- Google-hosted Inter, JetBrains Mono, and Material Symbols static font assets are allowed with system/SVG fallbacks. No third-party JavaScript, analytics, trackers, avatars, remote images, or runtime Tailwind CDN.
- Password/key/share plaintext exists only in short-lived client component/worker memory, never Server Components, React props serialized into HTML, local/session storage, IndexedDB, URL/query, logs, or error reporting.
- Replace every `href="#"`, mocked submit, fake link, demo counter, and unsupported function with a real route/action, a disabled explanation, or removal.
